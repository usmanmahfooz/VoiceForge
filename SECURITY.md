# Security Policy

VoiceForge is primarily designed for local use. Do not expose it to the public internet without authentication, authorization, rate limiting, restricted CORS origins, request-size limits, safe storage, and monitoring.

## Reporting a vulnerability

Please do not publish credentials, personal voice recordings, or exploitable details in a public issue. Contact the repository owner privately through GitHub to coordinate a report.

## Sensitive data

Never commit access tokens, passwords, private user data, generated speech, voice-cloning state files, or personal audio samples. Revoke any credential that may have been exposed.
